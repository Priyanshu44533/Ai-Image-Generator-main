# 🎨 Image Generation from Text and Voice Using GAN

## 📌 Project Overview

Image Generation from Text and Voice Using GAN is an AI-based project designed to generate images from user-provided text descriptions and voice commands. The system aims to convert human instructions into meaningful visual outputs using Artificial Intelligence and Deep Learning techniques.

The project provides a simple and interactive interface where users can enter a text prompt or provide a voice command to generate images. It aims to make AI-powered image generation easy, accessible, and user-friendly.

## 🎯 Objectives

- Generate images based on text descriptions.
- Support voice-based input for image generation.
- Explore Generative Adversarial Networks (GAN).
- Provide an interactive and user-friendly interface.
- Demonstrate the applications of Artificial Intelligence and Deep Learning.

## ✨ Key Features

- **Text-to-Image Generation:** Generate images using text prompts.
- **Voice Input:** Provide voice commands for image generation.
- **AI-Based Processing:** Convert user instructions into visual outputs.
- **User-Friendly Interface:** Simple and interactive design.
- **Image Display:** View generated images directly on the website.

## ⚙️ Installation and Setup

**Step 1: Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Open the project folder**

```bash
cd image-generator
```

**Step 3: Install dependencies**

```bash
npm install
```

**Step 4: Configure environment variables**

Create a `.env.local` file in the root directory and add your API credentials according to the image-generation provider being used.

```env
YOUR_API_KEY=your_api_key_here
```

**Step 5: Run the development server**

```bash
npm run dev
```

**Step 6: Open the application**

Visit:

```text
http://localhost:3000
```
